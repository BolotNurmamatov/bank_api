# Казначейский Дашборд (Treasury Dashboard)

Добро пожаловать в документацию проекта **Казначейский Дашборд**. Этот документ написан простым и понятным языком, чтобы любой сотрудник (независимо от технических навыков) мог понять, как работает система, для чего она нужна и как ей пользоваться.

---

## 1. Описание проекта

**Казначейский Дашборд** — это внутренняя система компании, которая автоматически собирает информацию об остатках денег на всех наших корпоративных банковских счетах и отображает её в удобном виде на едином экране.

Раньше сотрудникам приходилось вручную заходить в разные клиент-банки (Оптима, Элдик, Айыл Банк), выписывать остатки и сводить их в таблицы. Теперь система делает это сама в фоновом режиме каждые несколько минут.

### Главные преимущества:
- **Экономия времени:** Нет нужды заходить в каждый банк отдельно.
- **Точность данных:** Автоматический сбор исключает человеческий фактор (ошибки при переписывании цифр).
- **История изменений:** Система сохраняет данные, позволяя строить графики и видеть динамику остатков за день, неделю или месяц.
- **Безопасность:** Доступ к системе строго ограничен только доверенным сотрудникам компании.

## 2. Логика работы (Как это устроено)

Проект можно сравнить с умным роботом-секретарем:

1. **Сбор данных (Бэкенд):** Каждые несколько минут "робот" стучится в двери разных банков через специальные защищенные каналы связи (API) и спрашивает: *"Какой сейчас баланс на счете X?"*.
2. **Фильтрация:** Робот берет только нужные нам счета. Например, из всех счетов он отбирает только те, которые открыты в национальной валюте (KGS).
3. **Хранение (База данных):** Полученные ответы робот аккуратно записывает в огромный цифровой журнал (ClickHouse). Он записывает название банка, номер счета, сумму и точное время проверки.
4. **Отображение (Фронтенд):** Когда вы открываете сайт, система забирает последние записи из журнала и рисует красивые графики и таблицы прямо в вашем браузере. Данные на экране обновляются сами каждую минуту.

## 3. Разделы системы (Что внутри)

В системе есть несколько главных страниц, между которыми можно переключаться через боковое меню:

| Название раздела | Описание и назначение |
| :--- | :--- |
| **Главная (Дашборд)** | Сводка по всем банкам на одном экране. Здесь видно общую сумму денег, количество подключенных банков, число счетов и статус связи с банками. |
| **Банки** | Детальная таблица по каждому банку. Здесь можно увидеть конкретные номера расчетных счетов и точный баланс (с копейками) на каждом из них в режиме реального времени. |
| **Отчеты** | Страница с интерактивными графиками. Здесь можно визуально оценить динамику изменения остатков по каждому банку за последний час, сегодняшний день, неделю или целый месяц. |
| **Журнал запросов** | Внутренний раздел для аудита, где фиксируется, кто и когда заходил в систему. |

## 5. Подключенные Банки

На сегодняшний день система автоматически забирает данные из следующих банков:

| Логотип / Банк | Как забираем данные | Валюта |
| :--- | :--- | :--- |
| **Оптима Банк** | Через официальное API банка с использованием ключа `OPTIMA_API_KEY`. | KGS (Кыргызский сом) |
| **Элдик Банк** | Через систему Open API с использованием ключа `ELDIK_API_KEY`. | KGS (Кыргызский сом) |
| **Айыл Банк** | Процесс получения данных настроен через защищенный шлюз. | KGS (Кыргызский сом) |

*Примечание: Если банк проводит технические работы на своей стороне, его статус на главной странице может временно измениться на "Ошибка". Как только банк восстановит работу, система сама возобновит загрузку данных.*

## 6. Техническое обслуживание (Для IT-отдела)

Проект развернут на **Windows Server** с использованием менеджера процессов **PM2**.

Если вы внесли изменения в код (например, обновили формулы или добавили новые банки), вам необходимо зайти на сервер и обновить проект вручную через командную строку (PowerShell / CMD).

### 6.1. Обновление кода (Git Pull)
Сначала загрузите последние изменения из репозитория:
```powershell
cd "C:\Path\To\Your\api_bank"  # Укажите реальный путь к проекту
git pull origin main
```

### 6.2. Обновление Frontend (Визуальная часть)
Если изменения касались интерфейса (папка `frontend`), необходимо пересобрать приложение:
```powershell
cd frontend
npm install   # Если были добавлены новые библиотеки
npm run build
cd ..
```

### 6.3. Обновление Backend (Сбор данных)
Если были изменены Python скрипты (папка `backend`), достаточно просто перезапустить процесс.

### 6.4. Управление процессами через PM2
PM2 следит за тем, чтобы проект работал 24/7. Вот основные команды для управления сервером:

**Перезагрузка после обновления:**
```powershell
# Если вы обновили только бэкенд
pm2 restart api_bank_backend

# Если вы обновили фронтенд
pm2 restart api_bank_frontend

# Если нужно перезагрузить вообще всё
pm2 restart all
```

**Остановка и запуск:**
```powershell
# Остановить все процессы (Сайт перестанет работать)
pm2 stop all

# Запустить все остановленные процессы заново
pm2 start all

# Запустить проект с нуля (если конфигурация слетела)
pm2 start ecosystem.config.js
```

**Мониторинг:**
```powershell
# Посмотреть список всех запущенных сервисов и их статус (работает/ошибка)
pm2 status

# Посмотреть логи (полезно, если что-то сломалось)
pm2 logs

# Сохранить текущее состояние PM2 (чтобы проект сам включился при перезагрузке Windows)
pm2 save
```
