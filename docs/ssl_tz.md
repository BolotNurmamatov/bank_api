Шаг 1: Подготовка сервера
Сначала нужно выключить всё, что работало по старой схеме, чтобы освободить порты. Откройте PowerShell от имени администратора в папке проекта:

powershell
pm2 stop all
taskkill /F /IM nginx.exe
Шаг 2: Запуск через Docker
Убедитесь, что на сервере установлен Docker Desktop (и он запущен). Находясь в папке с проектом, введите:

powershell
docker compose up -d --build
Docker сам скачает нужные системы, соберет Frontend, Backend и поднимет новый Nginx. Проект будет доступен по локальному IP 10.45.12.47.

Шаг 3: Привязка домена (DNS)
Чтобы сайт открывался по красивому имени (например, bank.redpetroleum.kg), вам нужно зайти в панель управления доменами вашей компании (где покупался домен redpetroleum.kg). Там нужно создать A-запись (A-record):

Имя (Host): bank (или treasury)
Значение (IP): Впишите внешний IP-адрес вашего Windows-сервера.
Как только DNS обновится (от 10 минут до пары часов), сайт начнет открываться по вашему домену!

Шаг 4: Настройка HTTPS (SSL-сертификат)
Чтобы в браузере не писало "Не защищено", нам понадобится SSL-сертификат. Самый популярный бесплатный способ — это Certbot (от Let's Encrypt).

Установите Certbot на Windows-сервер (скачайте с официального сайта).
Выпустите сертификат для вашего нового домена.
Как только сертификат сгенерируется, мы добавим в наш файл nginx.conf пару строчек с путями к сертификату (я вам с этим помогу!) и откроем 443 порт.
